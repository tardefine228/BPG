Готовый комплект: частицы, короткий комиксный трассер, боезапас и поражение.

Код подготовлен под текущий BPG, Unity 6000.6.5f1, URP 2D и уже существующие меню. Рабочие Assets и сцены пока не изменены: этот комплект лежит вне Assets, чтобы ты установил его сам. Внутри Files сохранены будущие пути файлов в Unity.

**1. Установи код**

Останови Play Mode. Все пять файлов C# должны попасть в проект вместе, поскольку они ссылаются друг на друга.

| Файл внутри Files | Куда вставить в Unity | Что сделать / за что отвечает |
| --- | --- | --- |
| Assets/Scripts/Gun/SlingshotController.cs | Уже существующий файл с тем же путём | Полностью заменить содержимое. Расходует снаряд при фактическом запуске, запрещает новый запуск без боезапаса, включает трассер и отслеживает ещё движущиеся снаряды. |
| Assets/Scripts/LevelScripts/LevelSession.cs | Уже существующий файл с тем же путём | Полностью заменить содержимое. Настраивает лимит, показывает остаток, проверяет победу/поражение, создаёт плашку и её кнопки. Существующие очки, звёзды и звуки победы сохранены. |
| Assets/Scripts/MenusScripts/PauseMenuController.cs | Уже существующий файл с тем же путём | Полностью заменить содержимое. Не позволяет открыть паузу поверх итогового окна. |
| Assets/Scripts/ProjectileS/ProjectileComicEffects.cs | Новый файл с этим путём | Создать файл. Компонент для префаба снаряда: трассер и выбор эффекта попадания. |
| Assets/Scripts/ProjectileS/ComicParticleBurst.cs | Новый файл с этим путём | Создать файл. Временные вспышки, пыль и щепки на ParticleSystem, с автоматическим удалением. На объекты вручную его добавлять не надо. |
| Assets/Shaders/ComicFX.shader | Новый файл с этим путём | Создать папку Shaders, если её нет, и вставить шейдер. Показывает частицы и трассер с прозрачностью в URP 2D. |

Для трёх существующих скриптов именно замени текст внутри файлов: сохрани их имена и существующие .meta, чтобы Unity сохранила ссылки и настройки компонентов. Не оставляй копии этих классов внутри Assets. Не копируй в Assets целиком папку Tools/particles_and_ammo — только перечисленные файлы из Files.

У тебя GameManager — название объекта в Hierarchy. Отдельного GameManager.cs сейчас нет: за прохождение отвечает LevelSession на этом объекте. Создавать второй менеджер не требуется.

**2. Создай материал для эффектов**

1. В Project создай папку Assets/Materials/FX.
2. Внутри: Create → Material, назови M_ComicFX.
3. В Inspector у материала выбери Shader → BPG → ComicFX.
4. Tint оставь белым, Texture — белой/пустой.

Этот материал обязательно назначается на префабе. Благодаря ссылке из префаба Unity включит шейдер в сборку игры. Другие материалы снаряда, ящиков и земли менять не нужно.

**3. Подключи частицы и трассер**

1. Открой Assets/Prefabs/Projectile.prefab двойным щелчком.
2. На корневой объект Projectile, где уже есть Rigidbody2D и CircleCollider2D, добавь ProjectileComicEffects через Add Component.
3. В поле Comic Material перетащи M_ComicFX.
4. Сохрани префаб. Все пять сцен уже стреляют этим префабом, поэтому эффект появится во всех.

Не нужно вручную создавать ParticleSystem или TrailRenderer. Скрипты создают их при игре. Формы частиц тоже рисуются кодом: круглые клубочки пыли, щепки и звёздочки с тёмной обводкой.

Ящики определяются по LevelTarget на самом объекте или его родителе. Пыль появляется на поверхностях из Ground Layers. По умолчанию Ground Layers = Everything — этого достаточно для нынешних сцен. Если хочешь отдельную настройку, создай слой Ground, назначь его земле и площадкам с Collider2D, и выбери его в Ground Layers. Для составного объекта назначай слой именно объекту с коллайдером либо применяй смену слоя к детям. Не назначай земле Is Trigger: эффекты используют физические столкновения OnCollisionEnter2D.

Трассер включается в момент реального запуска, после движения камеры. При прицеливании его нет. Он заканчивается при первом столкновении и быстро затухает. Эффекты ударов продолжают работать и при последующих достаточно сильных столкновениях снаряда.

Стартовые настройки уже прописаны в коде:

| Поле ProjectileComicEffects | Значение | Как влияет |
| --- | --- | --- |

| Max Trail Length | 5 | Ограничивает длину следа на высокой скорости примерно пятью единицами мира. |
| Trail Width | 0.38 | Толщина цветной полосы. |
| Outline Width | 0.13 | Толщина тёмной обводки с каждой стороны. |
| Tail Offset | 0.35 | Смещение начала следа за снаряд. |
| Trail Color / Ink Color | Жёлтый / тёмный | Цвет основной полосы и обводки. По центру есть тонкая белая линия. |
| Dust Count / Chip Count | 9 / 7 | Количество клубочков пыли и щепок за удар. |
| Impact Scale | 1.5 | Общий размер и разлёт эффекта. При маленьком эффекте в общем обзоре попробуй 2–3. |

Эти эффекты показывают попадание. Они не разрушают ящик и не меняют его прочность: за это уже отвечает LevelTarget.

**4. Настрой пять снарядов на уровнях**

По очереди открой Gameplay, Level2, Level3, Level4, Level5. В каждой сцене:

1. Выбери GameManager в Hierarchy.
2. В компоненте LevelSession найди блок «Боезапас этого уровня».
3. Установи Max Projectiles = 5 и сохрани сцену. В новом коде 5 уже задано по умолчанию.
4. Убедись, что Gameplay Controller ссылается на SlingshotController этого же GameManager. В текущих сценах эта ссылка уже есть.

Чтобы изменить число снарядов конкретного уровня, меняй Max Projectiles в его сцене. Например, Level3 → GameManager → LevelSession → Max Projectiles = 8. После сохранения изменение относится к этой сцене.

Уже существующие компоненты LevelSession, SlingshotController и PauseMenuController не удаляй и заново не добавляй: замены текста файлов достаточно. Forced Level Id и ссылки на звуки сохраняются.

Счётчик «СНАРЯДЫ 5 / 5» создаётся автоматически под счётчиком очков. Снаряд расходуется только при запуске. Взять его мышью, прицелиться и отпустить без выстрела можно без расхода. Reload не восстанавливает потраченные снаряды. После пятого запуска шестой снаряд не создаётся.

**5. Что происходит после последнего выстрела**

Система сначала проверяет победу. Если последний ящик сбит пятым выстрелом, появляется обычное окно победы.

Если цели остались, система ждёт окончания текущего выстрела, возврата камеры, остановки всех выпущенных снарядов и оставшихся целей. Затем ждёт ещё Defeat Settle Delay, по умолчанию 1 секунду, и показывает «ПОРАЖЕНИЕ». Поэтому окно не перекрывает полёт последнего снаряда или падение ящика, которое ещё может принести победу.

На плашке две кнопки:

- «НАЧАТЬ ЗАНОВО» перезагружает текущую сцену, возвращает полный боезапас и исходное состояние ящиков.
- «ГЛАВНОЕ МЕНЮ» открывает MainMenu через существующий SceneTransition.

Плашка использует существующий MenuButtonStyle: тот же шрифт, кнопки, подсветка, звуки и переход сцены. Фон затемняется, светлая карточка создаётся кодом. При поражении физика ставится на паузу; перед перезапуском или уходом в меню время возвращается к норме. Поражение не записывает прохождение, звёзды и наградные очки.

Для ожидания остановки есть Target Settle Speed = 0.15 и Target Settle Angular Speed = 12. Обычно оставь их как есть. Если оставшаяся цель постоянно движется, проверка ждёт её остановки: принудительного таймера поражения здесь нет. Уже сбитые цели в ожидание не входят, поскольку они могут бесконечно падать за карту.

**6. Быстрая проверка после установки**

1. Убедись, что в Console нет ошибок компиляции. Материал M_ComicFX назначен на ProjectileComicEffects в префабе.
2. Потяни снаряд и отмени слабое прицеливание: счётчик остаётся 5 / 5, трассера нет.
3. Выстрели по земле: счётчик станет 4 / 5, за снарядом появится короткий след, на земле — пыль и маленькая вспышка.
4. Попади в ящик: появляются щепки, пыль и звёздочки; его прочность работает как раньше.
5. Сделай пять промахов: шестой снаряд не появляется; после остановки и возврата камеры выходит поражение. Escape не открывает паузу поверх него.
6. Нажми «НАЧАТЬ ЗАНОВО»: тот же уровень начинается с 5 / 5 и нормальной физикой.
7. Повтори поражение и нажми «ГЛАВНОЕ МЕНЮ»: откроется меню выбора уровня.
8. Для проверки победы последним снарядом на Gameplay временно поставь Max Projectiles = 1, сбей цель одним выстрелом: должно появиться окно победы. Потом верни 5.
9. Проверь паузу во время полёта и возврат в игру: расход не повторяется, эффекты продолжаются после снятия паузы.

Текущая проверка: весь C# этого комплекта скомпилирован вместе с остальными игровыми скриптами и установленными библиотеками Unity 6000.6.5f1 без ошибок. verify_compile.ps1 повторяет эту проверку без установки комплекта в Assets. Проверка компиляции не запускает игровой уровень и не проверяет внешний вид шейдера: пункты выше нужно пройти в Play Mode после ручной установки.

**Нюанс текущего баланса**

На Level5 есть ящик Hits To Clear = 6, а на Level3–5 несколько бронированных целей. При пяти снарядах прохождение может оказаться слишком трудным: это зависит от повторных столкновений и возможности сбросить ящик с площадки. Лимит сделан ровно 5, как ты попросил; прочность и расстановка сохранены.

В LevelProgress пороги трёх звёзд для уровней 2–5 сейчас равны 6, 12, 13 и 15 выстрелам. При лимите 5 любое успешное прохождение этих уровней даст 3 звезды. Если позже понадобится различать результат, подстрой ThreeStarShots/TwoStarShots в описаниях уровней LevelProgress вместе с их боезапасом.

Частицы испускаются с явной скоростью в плоскости XY; позиция задаётся в мировых координатах через EmitParams и Simulation Space = World. API сверено с [документацией Unity](https://docs.unity.com/en-us/engine/6000.7/script-reference/unityengine/particlesystem/emitparams/velocity), а совместимость C# — компилятором против библиотек твоего проекта.
