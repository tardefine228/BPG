# Звуки

Все звуковые эффекты игры синтезируются скриптом, сторонних сэмплов в проекте
нет. Запуск из корня репозитория (нужен только Python 3):

```bash
python3 Tools/audio_tools/gen_sfx.py
```

Скрипт пересобирает файлы в `Assets/Resources/Audio/`:

| Файл | Где играет |
|---|---|
| `Slingshot/CatMeowShort.wav` | одно «мяу», когда рогатку берут на натягивание |
| `Slingshot/CatMeowLong.wav` | долгое «мяяяууу», когда снаряд полетел |
| `Slingshot/SlingshotStretch.wav` | запасной звук натяжения (зациклено, громкость и питч растут с натяжением) |
| `Slingshot/SlingshotShot.wav` | запасной звук выстрела (хлопок резины) |
| `Victory/Victory1Stars.wav` | победа на одну звезду — скромный короткий отклик |
| `Victory/Victory2Stars.wav` | победа на две звезды — ответ из двух нот с аккордом |
| `Victory/Victory3Stars.wav` | победа на три звезды — восходящее арпеджио, аккорд и искорки |

Мяуканье сделано из синтеза голоса: пила с падающей/растущей высотой тона
проходит через две движущиеся форманты («мя» → «яу»), плюс дрожание и дыхание.

Звук взятия играет один раз (`aimSoundLoops` выключен); если включить его в
инспекторе `SlingshotController`, вернётся старое поведение — зацикленный звук
натяжения с растущей громкостью и питчем.

Звук выбирается по числу заработанных звёзд в `LevelSession`
(`PlayVictorySound`). Клипы можно заменить своими: либо положить файл с тем же
именем, либо подставить свой клип в поля `victory1StarsSound` /
`victory2StarsSound` / `victory3StarsSound` и `aimSound` / `shotSound` в
инспекторе.

Треки победы намеренно разные по длине и высоте — чем лучше результат, тем
длиннее и ярче фанфары:

* 1 звезда — C5 → G4, одна короткая фраза (~0.9 с);
* 2 звезды — C5 → G5 и мягкий аккорд (~1.2 с);
* 3 звезды — C5 → E5 → G5, аккорд C6 с шлейфом и искорками (~1.7 с).

Метки (`*.wav.meta`) пишутся один раз: дальше их владелец — Unity, скрипт их не
перезаписывает.
