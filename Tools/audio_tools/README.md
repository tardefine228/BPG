# Звуки

Два источника звука в проекте:

1. **Синтез** — `Tools/audio_tools/gen_sfx.py` (нужен только Python 3): звуки
   натяжения/выстрела и фанфары победы.
2. **Настоящая запись кота из интернета** — `Tools/audio_tools/import_meows.py`
   (нужны `numpy` и `soundfile`): мяуканье для рогатки.

```bash
python3 Tools/audio_tools/gen_sfx.py        # синтез: рогатка (запасные) + победа
python3 Tools/audio_tools/import_meows.py   # мяуканье из реальной записи
```

## Мяуканье рогатки (реальная запись, CC0)

Источник — registry-item `sfx-cat-meow` из репозитория
[crafter-station/elements](https://github.com/crafter-station/elements/blob/main/public/r/sfx-cat-meow.json)
(MIT; в описании самого звука: «Real cat meow for notifications and fun UI
interactions. **CC0 license**»). Внутри registry-json звук лежит как
`data:audio/mpeg;base64` в обычном текстовом файле, поэтому он доступен на
GitHub без LFS. Декодированная копия исходника закоммичена рядом:

```
Tools/audio_tools/sources/cat_meow_cc0.mp3   (0.78 с, моно, 44.1 кГц)
```

`import_meows.py` собирает из него два клипа:

| Файл | Как сделано | Где играет |
|---|---|---|
| `Slingshot/CatMeowShort.wav` | запись как есть: обрезана тишина, нормализовано до пика 0.85, мягкие края (~0.52 с) | короткое «мяу» при начале натяжения; сразу после него звучит `Assets/Audio/music for gun/slingshot-streched.mp3` |
| `Slingshot/CatMeowLong.wav` | тот же кот: тон ниже на 6 полутонов (ресемплинг), второй слой ещё на 4 полутона ниже (утолщение), растяжка гранулярным OLA до ~1.7 с, зал-хвост | долгое «мяяяууу», когда снаряд полетел |

Это по-прежнему живая запись, а не синтез: обработка — только обрезка,
нормализация, сдвиг тона и растяжка. Формат на выходе — 44100 Гц, моно,
PCM 16 бит. Метки (`*.wav.meta`) скрипт не трогает, поэтому GUID-ы клипов не
меняются и ссылки в сценах остаются рабочими. Параметры (питч, длина,
громкость зала) — константы в начале `import_meows.py`.

## Остальные звуки (синтез)

`gen_sfx.py` пересобирает файлы в `Assets/Resources/Audio/`. Скрипт также умеет
синтезировать запасное мяуканье (пила с движущимися формантами «мя» → «яу»,
дрожание, дыхание) — оно попадает в те же имена файлов, если запустить
`gen_sfx.py` после `import_meows.py`; чтобы вернуть реальную запись, запустите
`import_meows.py` снова.

| Файл | Где играет |
|---|---|
| `Slingshot/CatMeowShort.wav` | короткое «мяу» при начале натяжения (реальная запись) |
| `Assets/Audio/music for gun/slingshot-streched.mp3` | однократный звук сразу после мяуканья (назначен на Pull Sound в игровых сценах) |
| `Slingshot/CatMeowLong.wav` | долгое «мяяяууу», когда снаряд полетел (реальная запись, обработанная) |
| `Slingshot/SlingshotStretch.wav` | запасной синтезированный звук натяжения (в сценах не назначен) |
| `Slingshot/SlingshotShot.wav` | хлопок резины при выстреле (назначен на Shot Sound в игровых сценах) |
| `Victory/Victory1Stars.wav` | победа на одну звезду — скромный короткий отклик |
| `Victory/Victory2Stars.wav` | победа на две звезды — ответ из двух нот с аккордом |
| `Victory/Victory3Stars.wav` | победа на три звезды — восходящее арпеджио, аккорд и искорки |

В начале натяжения сначала проигрывается короткое мяу (`SlingshotController.Grab Meow`), затем, после окончания клипа, — `Pull Sound`. Звук выстрела задаётся на `AudioManager.Shot Sound`; в игровых сценах используется хлопок резины `SlingshotShot.wav`, не пушечный выстрел. Все эффекты подчиняются общей громкости.

Звук победы выбирается по числу заработанных звёзд в `LevelSession`
(`PlayVictorySound`). Клипы можно заменить своими: либо положить файл с тем же
именем, либо подставить свой клип в поля `victory1StarsSound` /
`victory2StarsSound` / `victory3StarsSound`, `pullSound`, `flightMeow` и
`shotSound` в инспекторе.

Треки победы намеренно разные по длине и высоте — чем лучше результат, тем
длиннее и ярче фанфары:

* 1 звезда — C5 → G4, одна короткая фраза (~0.9 с);
* 2 звезды — C5 → G5 и мягкий аккорд (~1.2 с);
* 3 звезды — C5 → E5 → G5, аккорд C6 с шлейфом и искорками (~1.7 с).

Метки (`*.wav.meta`) пишутся один раз: дальше их владелец — Unity, скрипты их не
перезаписывают.
