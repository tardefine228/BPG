# Инструменты для уровней

Постройки уровней и пиксельные превью карточек описаны одной раскладкой, поэтому
картинка в меню всегда соответствует сцене. Запускать из корня репозитория
(нужен только Python 3, внешних библиотек нет; кроме `check_layouts.py`):

```bash
python3 Tools/level_tools/level_layouts.py      # распечатать раскладки
python3 Tools/level_tools/apply_layouts.py      # записать постройки в сцены уровней
python3 Tools/level_tools/apply_layouts.py 3    # только уровень 3
python3 Tools/level_tools/apply_layouts.py --check   # только проверить YAML сцен
python3 Tools/level_tools/gen_previews.py       # Assets/Resources/LevelPreviews/level_1..5.png
pip install Box2D && python3 Tools/level_tools/check_layouts.py   # физическая проверка
```

## `level_layouts.py` — раскладки построек

Функции `level_1()` … `level_5()` описывают постройки в координатах относительно
`TargetArea` (её Y = 0, поэтому Y совпадает с мировым; верх земли — `GROUND_TOP = -2.61`).
Блоки ставятся «друг на друга» без ручного счёта высот:

```python
p = L.pillar("wood", 1.8, G, 2.4)      # вертикальная доска длиной 2.4 на земле
top = L.wood(0.0, p.top, 4.8, T)       # доска 4.8 x 0.6 на стойке
L.mouse(0.0, top.top)                  # мышь на доске
L.slab("StoneStep", 2.0, -1.41, 11.0, 2.4)   # неподвижная каменная площадка
```

* `wood` / `stone` — блоки из префабов `Assets/Prefabs/Blocks/WoodBlock` и `StoneBlock`;
  `pillar(...)` — та же доска, повёрнутая на 90°;
* `mouse` — `Assets/Prefabs/Mouse.prefab`; мышь всегда ставится на блок, не на землю;
* размеры кратны 0.1 — это один пиксель текстуры (Pixels Per Unit = 10);
* зазоры `BOX_GAP` / `MOUSE_GAP` повторяют «кожу» коллайдеров Unity, чтобы постройка
  с первого кадра лежала без толчка;
* `target_x`, `sling_x`, палитра неба и земли — для превью и проверок.

## `apply_layouts.py` — запись в сцены

**Заменяет всё содержимое `TargetArea`** в `Gameplay` и `Level2…Level5` экземплярами
префабов, ставит `TargetArea` в центр постройки, подбирает размер камеры «Цель»
(`Impact Size`), переносит каменные площадки (`StoneStep`, `TowerBase`, `RightPodium`),
рисует их каменной текстурой и удаляет лишние, ставит тег `Ground` на `FlatGround`
и площадки. UI, камера, звук и остальные объекты не трогаются. Перед записью скрипт
проверяет YAML: все ссылки fileID, связи Transform ↔ дети, экземпляры префабов и
`SceneRoots`; при ошибке сцена не перезаписывается.

Если постройку уже правили вручную в Unity, сначала перенесите правки в раскладку —
иначе они будут заменены.

## `gen_previews.py` — пиксельные превью карточек

Рисует сцену в стиле Angry Birds по раскладке: катапульта с рыжим котом и пунктиром
траектории слева, постройка из дерева и камня справа, серые пиксельные мыши вместо
свиней, небо и земля в палитре уровня (день, сумерки, ночь, закат). Холст 131×120
(пропорции окна превью 380×348) увеличивается в 4 раза «ближайшим соседом».
Существующие `.meta` (GUID и импорт без сжатия) не меняются.

## `check_layouts.py` — проверка в Box2D (необязательно)

Box2D — тот же движок, что у физики Unity 2D; повторяются настройки проекта
(шаг 0.02, итерации 8/3, материалы, параметры снаряда). Скрипт проверяет, что блоки
не пересекаются и на что-то опираются, мыши стоят только на блоках, постройка
12 секунд стоит без сдвигов, а перебор углов и силы выстрела показывает, сколько
мышей можно победить одним выстрелом. Правила урона совпадают с `MouseTarget`.

## `gen_levels.py` — старый генератор (остановлен)

Собирал сцены 2–5 клонированием объектов первого уровня. После переноса UI в сцены
он остановлен защитной проверкой, потому что потерял бы интерфейс. Новые уровни
создаются дублированием `Gameplay` в Unity (см. `REFACTORING.md`), а постройки в них
можно описать в `level_layouts.py` и записать `apply_layouts.py`. После добавления
сцены не забудьте `ProjectSettings/EditorBuildSettings.asset` и `LevelProgress.Levels`.
