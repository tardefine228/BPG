# Инструменты для уровней

Сцены уровней 2–5 и картинки-превью для меню сделаны скриптами, а не вручную,
поэтому их легко перегенерировать, когда поменяется расстановка.

Запускать из корня репозитория (нужен только Python 3, внешних библиотек нет):

```bash
python3 Tools/level_tools/gen_levels.py     # Assets/Scenes/Level2..5.unity
python3 Tools/level_tools/gen_previews.py   # Assets/Resources/LevelPreviews/level_4,5.png
```

`gen_levels.py` собирает сцены из объектов рабочего первого уровня
(`Assets/Scenes/Gameplay.unity`): клонирует нужные объекты и подменяет только
позиции, цвета, границы карты и блоки-мишени. Раскладка уровней описана
словарями `LEVEL2` … `LEVEL5` в конце файла:

* `slingshot_x` — где стоит катапульта;
* `target_area` — куда сдвинута группа мишеней;
* `blocks` — список блоков: имя, позиция, масштаб, масса, цвет и `hits`
  (прочность, то же поле `Hits To Clear`, что и в инспекторе);
* `slabs` — статичные каменные площадки (подиумы);
* `ground_color`, `background_color`, `light_color`, `map_min`, `map_max`,
  `impact_size` — палитра, границы камеры и приближение после выстрела.

Полезные мелочи:

* `GROUND_TOP` — высота поверхности земли, `on_ground()` / `on_top()` считают
  позицию блока так, чтобы он стоял на земле или на другом блоке;
* генератор сам проверяет результат (все ссылки fileID, связь transform ↔ дети,
  SceneRoots) и не перезаписывает сцену, если проверка не прошла;
* после генерации новых сцен не забудьте добавить их в
  `ProjectSettings/EditorBuildSettings.asset` и в `LevelProgress.Levels`.

`gen_previews.py` рисует превью-картинки карточек меню прямо из этих же
словарей раскладки, поэтому картинка всегда соответствует сцене.
