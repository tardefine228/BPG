# Пиксельные спрайты

`gen_sprites.py` рисует пиксель-арт игры (нужен только Python 3, внешних библиотек нет):

```bash
python3 Tools/art_tools/gen_sprites.py
```

| Файл | Что это |
| --- | --- |
| `Assets/Sprites/Blocks/Wood.png` | Дерево 32×32 с рамкой 2 px: 9-slice для режима Tiled у SpriteRenderer. |
| `Assets/Sprites/Blocks/Stone.png` | Каменная кладка 32×32 с рамкой 2 px; ею же нарисованы каменные площадки. |
| `Assets/Sprites/Mouse/Mouse.png` | Временная серая мышь 24×16, смотрит влево на катапульту. |
| `Assets/UI/Generated/StarOn.png`, `StarOff.png` | Звёзды 96×96 лучом вверх (раньше были перевёрнуты). |

Все пиксельные спрайты импортируются с Pixels Per Unit = 10, фильтром Point и без
сжатия, поэтому один пиксель текстуры равен 0.1 единицы мира и не размывается.
Существующие `.meta` (GUID) скрипт не трогает — ссылки в сценах и префабах сохраняются.

Мышь нарисована строками символов в `MOUSE_ART`: поменяйте символы и перезапустите
скрипт, либо просто замените `Mouse.png` своей текстурой (или назначьте другой спрайт
в `Assets/Prefabs/Mouse.prefab`) и подгоните CapsuleCollider2D.

`pixel_art.py` — общая мини-библиотека: холст RGBA, прямоугольники, линии, эллипсы,
увеличение «ближайшим соседом», запись и чтение PNG. Её же использует генератор
превью уровней `Tools/level_tools/gen_previews.py`.
