Изменения камеры, меню и загрузки

Сцены в сборке: Boot → MainMenu → Gameplay → Level2 → Level3 → Level4 → Level5. Для проверки полного запуска откройте Boot и нажмите Play. При запуске напрямую из уровня или MainMenu стартовая заставка пропускается, а переходы между сценами продолжают работать.

Заставка и переходы настраиваются в Assets/Resources/SceneTransitionSettings.asset:

| Поле в Inspector | Что вставить / изменить |
| --- | --- |
| Logo | Свой логотип. Импортируйте PNG как Sprite (2D and UI) и перетащите сюда. Область 560 × 210 сохраняет пропорции изображения. |
| Title | Название игры. Пока стоит «НАЗВАНИЕ ИГРЫ». Если задан логотип, название появится под ним. |
| Subtitle | Название студии или слоган. Пока стоит «СТУДИЯ / ВАШ СЛОГАН». |
| Startup Caption | Текст во время заставки. |
| Loading Caption | Текст загрузки между сценами. |
| Startup Hold | Показ логотипа перед загрузкой главного меню: 1,5 секунды. |
| Minimum Loading Time | Минимальное время индикатора загрузки: 0,65 секунды. Если сцена загружается дольше, экран ждёт её готовности. |
| Fade Duration | Появление / исчезновение экрана: 0,3 секунды. |
| Background / Text / Accent Color | Фон, текст и цвет полоски прогресса. |

Assets/Scenes/Boot.unity — короткая начальная сцена с камерой и StartupController. В ней нет AudioManager. Музыка главного меню начинает играть только после исчезновения заставки.

Assets/Scripts/SceneTrans/SceneTransition.cs — один общий экран, который сохраняется между сценами: затемняет текущую сцену, показывает загрузку, асинхронно загружает следующую и плавно открывает её. Новый переход вызывается через SceneTransition.Load("ИмяСцены"). В момент загрузки интерфейс перекрыт и Escape / стрельба заблокированы.

Assets/Scripts/SceneTrans/SceneTransitionSettings.cs — описание полей asset с настройками. Assets/Scripts/MenusScripts/StartupController.cs — запуск заставки и переход в MainMenu.

В MainMenu выбор уровня находится в MainButtons → LevelSelectPanel. У панели есть CanvasGroup и LevelSelectController; интерфейс создаётся внутри панели при запуске, карточки и звёзды обновляются при каждом открытии. MenuManager автоматически находит панель, если потеряна ссылка в Inspector. Кнопка «ИГРАТЬ» открывает панель, «НАЗАД» и Escape закрывают её. Если открыто сообщение «СКОРО», первое нажатие Escape закрывает сообщение. Отдельная сцена LevelSelect удалена. Выход из любого уровня и кнопка после прохождения возвращают сразу в главное меню через экран загрузки. Существующие сохранения звёзд, очков и громкости сохранены.

Все пять уровней товарища сохранены. Карточки разбиты на две страницы с маской по краям; работают стрелки, точки, колесо, свайп и клавиши влево/вправо. Стрелки и «НАЗАД» используют MenuButtonStyle, как остальной интерфейс. По умолчанию следующий уровень открывается после прохождения предыдущего. Для проверки можно включить Unlock All Levels на LevelSelectController в MainMenu. Номер уровня для запуска из редактора задан в LevelSession → Forced Level Id. Сохранены бронированные блоки с несколькими попаданиями, сопротивлением сдвигу и дополнительным трением, пороги звёзд для новых уровней и джинглы победы.

Assets/Scripts/MenusScripts/MenuManager.cs — переключение панелей главного меню. Assets/Scripts/MenusScripts/PanelFade.cs — плавное появление и исчезновение через CanvasGroup, работает и при Time.timeScale = 0. PauseMenuController использует его для паузы и настроек. Общий внешний вид кнопок по-прежнему задаётся в Assets/Resources/MenuButtonStyle.asset.

Кнопка «Эффекты: ВКЛ/ВЫКЛ» убрана по согласованному выбору; ползунки музыки и эффектов остались.

Звуки настраиваются на AudioManager в каждой сцене уровня: Shot Sound — звук выстрела (сейчас GunFire), Shot Sound Volume — его относительная громкость. Короткое мяу при взятии снаряда и длинное мяу при запуске задаются на GameManager → SlingshotController: Grab Meow / Flight Meow и их громкости. Новые записи лежат в Assets/Resources/Audio/Slingshot. Выстрел и длинное мяу звучат вместе при фактическом запуске, после задержки камеры. Все эти звуки, джинглы победы и звуки кнопок подчиняются ползунку эффектов. AudioManager сохраняется между сценами и получает настройки выстрела от загружаемого уровня.

Камера настраивается на Main Camera в Gameplay, компонент GameplayCameraController:

| Поле | Значение и назначение |
| --- | --- |
| Shot Launcher Size | 20: умеренное приближение перед выстрелом. |
| Transition Duration | 0,5 секунды на приближение. |
| Pre Shot Hold | 1 секунда у катапульты, затем выстрел. |
| Follow Size | 20: масштаб при слежении за снарядом. |
| Follow Sharpness / Look Ahead | Плавность и небольшой взгляд вперёд по скорости снаряда. |
| Impact Size | 12: масштаб места попадания. |
| Ground Hold / Building Hold | 1 / 2 секунды показа места падения / разрушения. |
| Return Duration | 0,7 секунды на возвращение к общему обзору. |

Камера следует до фактического первого столкновения. Попадание в объект с LevelTarget или дочерний объект TargetArea считается попаданием в постройку. Для объектов TargetArea камера удерживает общий центр здания, даже когда обломки разлетаются. После промаха она держит место контакта с землёй. Земля и фон автоматически покрывают края обзора, в том числе при полёте за исходные границы карты. Экран завершения уровня дожидается окончания показа попадания.

Assets/Scripts/Gun/SlingshotController.cs на GameManager отвечает за сопротивление воздуха и точки траектории. Air Resistance = 0,06 даёт небольшое замедление; Launch Power = 25 сохраняет последний баланс вашей ветки. Трение при приземлении сохранено. Прогноз использует тот же фиксированный шаг гравитации и сопротивления, что и физика снаряда. Все пять сцен используют эти настройки и кинематографичную камеру.

Trajectory Dot Pixels = 12 задаёт диаметр точки на экране; Dot Time Spacing = 0,12 — интервал между точками по времени полёта. Weak / Medium / Strong Pull Color задают красный → жёлтый → зелёный при росте натяжения. Точки обрываются в первом прогнозируемом столкновении. Старая непрерывная линия выключена.
