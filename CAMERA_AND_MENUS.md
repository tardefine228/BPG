Изменения камеры, меню и загрузки

Сцены в сборке: Boot → MainMenu → Gameplay → Level2 → Level3 → Level4 → Level5. Для проверки полного запуска откройте Boot и нажмите Play. При запуске напрямую из уровня или MainMenu стартовая заставка пропускается, а переходы между сценами продолжают работать.

Заставка и переходы настраиваются в Assets/Resources/SceneTransitionSettings.asset:

| Поле в Inspector | Что вставить / изменить |
| --- | --- |
| Logo | Свой логотип. Импортируйте PNG как Sprite (2D and UI) и перетащите сюда. Область 560 × 210 сохраняет пропорции изображения. |
| Title | Название игры. Пока стоит «НАЗВАНИЕ ИГРЫ». После смены логотипа примените оформление в prefab SceneTransition через контекстное меню компонента, чтобы переставить название под ним. |
| Subtitle | Название студии или слоган. Пока стоит «СТУДИЯ / ВАШ СЛОГАН». |
| Startup Caption | Текст во время заставки. |
| Loading Caption | Текст загрузки между сценами. |
| Startup Hold | Показ логотипа перед загрузкой главного меню: 1,5 секунды. |
| Minimum Loading Time | Минимальное время индикатора загрузки: 0,65 секунды. Если сцена загружается дольше, экран ждёт её готовности. |
| Fade Duration | Появление / исчезновение экрана: 0,3 секунды. |
| Background / Text / Accent Color | Палитра для явного применения через контекстное меню SceneTransition в prefab. |

Assets/Scenes/Boot.unity — короткая начальная сцена с камерой и StartupController. В ней нет AudioManager. Музыка главного меню начинает играть только после исчезновения заставки.

Assets/Scripts/SceneTrans/SceneTransition.cs — готовый экран из prefab в каждой сцене, который передаёт состояние перехода следующей сцене: затемняет текущую сцену, показывает загрузку, асинхронно загружает следующую и плавно открывает её. Новый переход вызывается через SceneTransition.Load("ИмяСцены"). В момент загрузки интерфейс перекрыт и Escape / стрельба заблокированы.

Assets/Scripts/SceneTrans/SceneTransitionSettings.cs — описание полей asset с настройками. Assets/Scripts/MenusScripts/StartupController.cs — запуск заставки и переход в MainMenu.

В MainMenu выбор уровня находится в MainButtons → LevelSelectPanel. У панели есть CanvasGroup и LevelSelectController; интерфейс сохранён внутри панели, состояние карточек и звёзд обновляется при каждом открытии. Ссылки MenuManager назначены в Inspector. Кнопка «ИГРАТЬ» открывает панель, «НАЗАД» и Escape закрывают её. Если открыто сообщение «СКОРО», первое нажатие Escape закрывает сообщение. Отдельная сцена LevelSelect удалена. Выход из любого уровня возвращает в главное меню через экран загрузки. Кнопка после прохождения открывает следующий уровень; после пятого возвращает в меню. Существующие сохранения звёзд, очков и громкости сохранены.

Все пять уровней товарища сохранены. Карточки разбиты на две страницы с маской по краям; работают стрелки, точки, колесо, свайп и клавиши влево/вправо. Стрелки и «НАЗАД» используют MenuButtonStyle, как остальной интерфейс. По умолчанию следующий уровень открывается после прохождения предыдущего. Для проверки можно включить Unlock All Levels на LevelSelectController в MainMenu. Номер уровня для запуска из редактора задан в LevelSession → Forced Level Id. Сохранены бронированные блоки с несколькими попаданиями, сопротивлением сдвигу и дополнительным трением, пороги звёзд для новых уровней и джинглы победы.

Assets/Scripts/MenusScripts/MenuManager.cs — переключение панелей главного меню. Assets/Scripts/MenusScripts/PanelFade.cs — плавное появление и исчезновение через CanvasGroup, работает и при Time.timeScale = 0. PauseMenuController использует его для паузы и настроек. Оформление задаётся на кнопках сцен. Прежний Assets/Resources/MenuButtonStyle.asset можно применить вручную через контекстное меню MenuControlFeedback.

Кнопка «В МЕНЮ» на панели паузы любого уровня сразу открывает выбор уровня в MainMenu. Панель подготовлена до исчезновения экрана загрузки; кнопка «НАЗАД» возвращает к начальной странице меню. Этот запрос одноразовый и не влияет на обычный запуск игры.

Кнопка «Эффекты: ВКЛ/ВЫКЛ» убрана по согласованному выбору; ползунки музыки и эффектов остались.

Звуки настраиваются на AudioManager в каждой сцене уровня: Shot Sound — звук выстрела (сейчас GunFire), Shot Sound Volume — его относительная громкость. Короткое мяу при взятии снаряда и длинное мяу при запуске задаются на GameManager → SlingshotController: Grab Meow / Flight Meow и их громкости. Новые записи лежат в Assets/Resources/Audio/Slingshot. Выстрел и длинное мяу звучат вместе при фактическом запуске, после задержки камеры. Все эти звуки, джинглы победы и звуки кнопок подчиняются ползунку эффектов. AudioManager сохраняется между сценами и получает настройки выстрела от загружаемого уровня.

Камера настраивается на Main Camera → GameplayCameraController во всех пяти уровнях.

| Поле | Назначение |
| --- | --- |
| Map Min / Map Max | Границы всей карты: (-38, -7.5) — (38, 29). Камера помещает их в кадр при текущих пропорциях экрана. |
| Overview Padding | Запас по краям кадра, 1.5. |
| Intro Zoom | Ползунок 0–0.35: насколько дальше камера в начале; по умолчанию 0.12, то есть 12%. 0 отключает приближение. |
| Intro Duration | Ползунок длительности приближения, по умолчанию 1.2 секунды. |

В редакторе камера уже показывает конечный игровой кадр: её позиция и Size сохранены в сценах и обновляются при изменении Map Min / Map Max. Кнопка «Показать карту в окне Scene» на GameplayCameraController выставляет удобный обзор сцены.

После загрузки и закрытия обучения камера плавно приближается и остаётся на месте. Пауза останавливает приближение; при перезапуске оно повторяется. Камера больше не следует за снарядом и не переключается к месту попадания. Три кнопки обзора вместе с GameplayCameraCanvas удалены из всех пяти сцен. Счёт расположен слева сверху, пауза — справа сверху.

Расстояние между катапультой и постройками сокращено ещё примерно вдвое. Конструкции, подиумы, мыши и боезапас сохранены. Под мышами, которые раньше начинали на полу, добавлены небольшие разрушаемые деревянные опоры; они не обязательны для победы. Сила и гравитация выстрела пересчитаны для короткого поля.

GameManager → SlingshotController:

- Projectile Gravity Scale — сила гравитации снаряда. Уменьшайте, чтобы кот летел дальше при прежней начальной скорости; дуга станет выше, время полёта — больше. Гравитация подобрана отдельно для каждого уровня, чтобы полный выстрел мог достать крайнюю мышь. Launch Power менять для этого не нужно.
- Min / Max Launch Angle — направление выстрела, по умолчанию 0–65°. Обратное натяжение не стреляет.
- Max Arm Tilt — наклон рычага относительно сохранённой позы, по умолчанию до 35°. Рычаг начинает с центральной приподнятой позы (-55°) и отклоняется назад, к очереди. Кот закреплён на LaunchPoint до выстрела. Рычаг и следующий кот возвращаются в исходную позу после отмены или запуска.
- Weak / Medium / Strong Pull Color — светлые красный, жёлтый и зелёный цвета точек.
- Trajectory Shadow Offset Pixels — смещение тени в пикселях, по умолчанию (-2, -2), то есть слева снизу.
- Trajectory Shadow Color — цвет и прозрачность тени.

MouseEnemy на Assets/Prefabs/MouseEnemy.prefab отвечает за мышей. Floor можно назначить вручную; пустое поле берёт коллайдер земли из камеры уровня. Контакт с полом убивает мышь независимо от скорости и высоты падения. Прямое попадание CatProjectile / ProjectileImpactReporter снимает всё здоровье. Прочие столкновения и способности сохраняют систему урона. События смерти и начисления очков срабатывают один раз. Физика и коллайдеры отключаются в момент касания. Поза гибели, отлёт с вращением, облачко и затухание задаются в MouseEnemy → «Отлёт при гибели» (Death Sprite / Duration / Hop Speed / Sideways Speed / Gravity / Spin Speed). Пауза останавливает анимацию.

Коллайдер мышей: откройте Assets/Prefabs/MouseEnemy.prefab, компонент Box Collider 2D. Edit Collider правит контур, Size — ширину и высоту, Offset — смещение. Круглый коллайдер заменён прямоугольным, а Rigidbody 2D → Constraints → Freeze Rotation Z удерживает мышь вертикально. Для другого типа сначала добавьте нужный Collider 2D, затем удалите Box Collider 2D; Cat1–Cat5 по-прежнему используют Circle Collider 2D для круглых котов.

Проверка в отдельной копии проекта: `Tools/validation/run_play_checks.ps1 -CompactGameplayOnly -MinimalEditor`.

Текущий Projectile Gravity Scale по уровням: Gameplay — 2.772456; Level2 — 2.315277; Level3 — 1.887754; Level4 — 1.994785; Level5 — 2.055694. Сила запуска сохранена.

Проверено в Unity 6000.6.5f1: все пять сцен, 19 выстрелов, исходный кадр в редакторе, 4:3 и 16:9, кот в ковше, наклон назад, дальность до крайней мыши, очередь, пауза, рестарт, прямоугольные коллайдеры мышей, мгновенная гибель, попадание снаряда, отлёт и затухание. Результат — PASS без игровых ошибок.
