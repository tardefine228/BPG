Изменения камеры, меню и загрузки

Сцены в сборке: Boot → MainMenu → Gameplay → Level2 → Level3 → Level4 → Level5. Для проверки полного запуска откройте Boot и нажмите Play. При запуске напрямую из уровня или MainMenu стартовая заставка пропускается, а переходы между сценами продолжают работать.

Заставка и переходы настраиваются в Assets/Resources/SceneTransitionSettings.asset:

| Поле в Inspector | Что вставить / изменить |
| --- | --- |
| Logo | Свой логотип. Импортируйте PNG как Sprite (2D and UI) и перетащите сюда. Область 560 × 210 сохраняет пропорции изображения. |
| Title | Название игры: «КОТАПУЛЬТА». После смены логотипа примените оформление в prefab SceneTransition через контекстное меню компонента, чтобы переставить название под ним. |
| Subtitle | Название студии: «BP GAMES». |
| Startup Caption | Текст во время заставки. |
| Loading Caption | Текст загрузки между сценами. |
| Startup Hold | Показ логотипа перед загрузкой главного меню: 1,5 секунды. |
| Minimum Loading Time | Минимальное время индикатора загрузки: 0,65 секунды. Если сцена загружается дольше, экран ждёт её готовности. |
| Fade Duration | Появление / исчезновение экрана: 0,3 секунды. |
| Background / Text / Accent Color | Палитра для явного применения через контекстное меню SceneTransition в prefab. |

Assets/Scenes/Boot.unity — короткая начальная сцена с камерой и StartupController. В ней нет AudioManager. Музыка главного меню начинает играть только после исчезновения заставки.

Assets/Scripts/SceneTrans/SceneTransition.cs — готовый экран из prefab в каждой сцене, который передаёт состояние перехода следующей сцене: затемняет текущую сцену, показывает загрузку, асинхронно загружает следующую и плавно открывает её. Новый переход вызывается через SceneTransition.Load("ИмяСцены"). В момент загрузки интерфейс перекрыт и Escape / стрельба заблокированы.

Assets/Scripts/SceneTrans/SceneTransitionSettings.cs — описание полей asset с настройками. Assets/Scripts/MenusScripts/StartupController.cs — запуск заставки и переход в MainMenu.

В MainMenu выбор уровня находится в MainButtons → LevelSelectPanel. У панели есть CanvasGroup и LevelSelectController; интерфейс сохранён внутри панели, состояние карточек и звёзд обновляется при каждом открытии. Ссылки MenuManager назначены в Inspector. Кнопка «ИГРАТЬ» открывает панель, «НАЗАД» и Escape закрывают её. Если открыто сообщение «СКОРО», первое нажатие Escape закрывает сообщение. Отдельная сцена LevelSelect удалена. Выход из любого уровня возвращает в главное меню через экран загрузки. Кнопка после прохождения открывает следующий уровень; после пятого возвращает в меню. Существующие сохранения звёзд, очков и громкости сохранены.

Карточки разбиты на две страницы с маской по краям; работают стрелки, точки, колесо, свайп и клавиши влево/вправо. Оранжевая обводка (объекты HoverHighlight_1…5 за карточками) появляется только при наведении курсора на открытый уровень и исчезает, когда курсор уходит; на закрытых уровнях её нет. Превью карточек — пиксельные картинки в стиле Angry Birds из Assets/Resources/LevelPreviews, их рисует Tools/level_tools/gen_previews.py по раскладкам построек. Стрелки и «НАЗАД» используют MenuButtonStyle, как остальной интерфейс. По умолчанию следующий уровень открывается после прохождения предыдущего. Для проверки можно включить Unlock All Levels на LevelSelectController в MainMenu. Номер уровня для запуска из редактора задан в LevelSession → Forced Level Id. Сохранены бронированные (каменные) блоки с несколькими попаданиями, сопротивлением сдвигу и дополнительным трением, а также джинглы победы. Подробности о постройках и мышах — в разделе «Постройки и мыши» ниже.

Assets/Scripts/MenusScripts/MenuManager.cs — переключение панелей главного меню. Assets/Scripts/MenusScripts/PanelFade.cs — плавное появление и исчезновение через CanvasGroup, работает и при Time.timeScale = 0. PauseMenuController использует его для паузы и настроек. Оформление задаётся на кнопках сцен. Прежний Assets/Resources/MenuButtonStyle.asset можно применить вручную через контекстное меню MenuControlFeedback.

Кнопка «В МЕНЮ» на панели паузы любого уровня сразу открывает выбор уровня в MainMenu. Панель подготовлена до исчезновения экрана загрузки; кнопка «НАЗАД» возвращает к начальной странице меню. Этот запрос одноразовый и не влияет на обычный запуск игры.

Кнопка «Эффекты: ВКЛ/ВЫКЛ» убрана по согласованному выбору; ползунки музыки и эффектов остались.

Звуки настраиваются на AudioManager в каждой сцене уровня: Shot Sound — звук выстрела (сейчас GunFire), Shot Sound Volume — его относительная громкость. Короткое мяу при взятии снаряда и длинное мяу при запуске задаются на GameManager → SlingshotController: Grab Meow / Flight Meow и их громкости. Новые записи лежат в Assets/Resources/Audio/Slingshot. Выстрел и длинное мяу звучат вместе при фактическом запуске, после задержки камеры. Все эти звуки, джинглы победы и звуки кнопок подчиняются ползунку эффектов. AudioManager сохраняется между сценами и получает настройки выстрела от загружаемого уровня.

Камера настраивается на Main Camera в Gameplay, компонент GameplayCameraController:

| Поле | Значение и назначение |
| --- | --- |
| Shot Launcher Size | 20: умеренное приближение перед выстрелом. |
| Transition Duration | 0,5 секунды на приближение. |
| Pre Shot Hold | 1 секунда у катапульты, затем выстрел. |
| Follow Size | 20: масштаб при слежении за снарядом. |
| Follow Sharpness / Look Ahead | Плавность и небольшой взгляд вперёд по скорости снаряда. |
| Impact Size | 12: масштаб ручной кнопки «ЦЕЛЬ». |
| Impact Transition Duration | 0,75 секунды на перемещение к попаданию с сохранением масштаба полёта. |
| Ground Hold / Building Hold | 1 / 2 секунды показа места падения / разрушения. |
| Return Duration | 0,7 секунды на возвращение к общему обзору. |
| Оттенок выбранной кнопки | Лёгкий тёплый оттенок текущего режима камеры. Можно изменить на Main Camera → GameplayCameraController в каждом уровне. |

Выбранный режим камеры отмечается цветом фона кнопки отдельно от её доступности. При паузе кнопки остаются видимыми и сохраняют отметку выбора, но нажатия заблокированы. Disabled Color у кнопок камеры и паузы совпадает с Normal Color, поэтому они затемняются общей панелью без дополнительного серого оттенка. Короткая подпись под переключателями камеры удалена из всех пяти сцен.

Камера следует до фактического первого столкновения. Попадание в объект с LevelTarget или дочерний объект TargetArea считается попаданием в постройку. Для объектов TargetArea камера удерживает общий центр здания, даже когда обломки разлетаются. После промаха она держит место контакта с землёй. Земля и фон автоматически покрывают края обзора, в том числе при полёте за исходные границы карты. Экран завершения уровня дожидается окончания показа попадания.

Assets/Scripts/Gun/SlingshotController.cs на GameManager отвечает за сопротивление воздуха и точки траектории. Air Resistance = 0,06 даёт небольшое замедление; Launch Power = 25 сохраняет последний баланс вашей ветки. Трение при приземлении сохранено. Прогноз использует тот же фиксированный шаг гравитации и сопротивления, что и физика снаряда. Все пять сцен используют эти настройки и кинематографичную камеру.

Trajectory Dot Pixels = 12 задаёт диаметр точки на экране; Dot Time Spacing = 0,12 — интервал между точками по времени полёта. Weak / Medium / Strong Pull Color задают красный → жёлтый → зелёный при росте натяжения. Точки обрываются в первом прогнозируемом столкновении. Старая непрерывная линия выключена.

## Постройки и мыши

На каждом уровне внутри объекта TargetArea стоит постройка из блоков, а на ней — серые мыши (аналог свиней в Angry Birds). Уровень пройден, когда побеждены все мыши; блоки по-прежнему приносят очки, но для победы сбивать их не нужно. Если на уровне нет ни одной мыши, действует старое правило — сбить все блоки.

| Уровень | Постройка | Блоков | Мышей | Котов | 3 звезды / 2 звезды |
| --- | --- | --- | --- | --- | --- |
| 1 | Скамейка: две стойки и доска | 3 | 1 | 2 | 1 / 2 выстрела |
| 2 | Двухэтажная башня, каменные упоры | 8 | 2 | 3 | 2 / 3 |
| 3 | Две башни на каменных основаниях, мост с хижиной | 12 | 3 | 4 | 2 / 3 |
| 4 | Блиндаж и крепость на каменной ступени, каменная крыша | 16 | 3 | 5 | 2 / 4 |
| 5 | Замок на цоколе: открытая слева комната, балкон у башенки, сторожевая вышка | 21 | 4 | 5 | 3 / 4 |

Пороги звёзд задаются в `LevelProgress.Levels`, боезапас (котов) — в `LevelSession → Max Projectiles` (см. `CATS_AND_QUEUE.md`); на каждом уровне котов хотя бы на одного больше, чем мышей. Мыши никогда не стоят на земле — только на блоках. Устойчивость построек и возможность сбить каждую мышь проверены симуляцией в Box2D (тот же физический движок, что у Unity 2D): `Tools/level_tools/check_layouts.py`. Кот наносит только один удар и после него улетает за поле (`CatFlightEffects`), поэтому каждая мышь достижима прямым выстрелом, а для трёх звёзд на уровнях 3–5 нужен выстрел, который побеждает сразу двух мышей. Проверка в Unity, что после загрузки постройки стоят, мыши живы и уровень не завершается сам: `Tools/validation/run_play_checks.ps1 -StructuresOnly -MinimalEditor`.

**Мышь** — `Assets/Prefabs/Mouse.prefab`, компонент `MouseTarget`:

| Поле | Значение и назначение |
| --- | --- |
| Lives | Жизни, по умолчанию 2. |
| Damage Speed | Удар со скоростью от 4 отнимает одну жизнь. |
| Lethal Speed | Удар со скоростью от 10 (прямое попадание кота, летящий блок) отнимает все жизни. |
| Hit Cooldown | Пауза между засчитанными ударами: 0,2 с. |
| Settle Time | Первую секунду после загрузки удары и касания не засчитываются, пока постройка оседает. |
| Ground Tag | Касание объекта с тегом Ground сразу отнимает все жизни. Тег стоит на FlatGround и каменных площадках всех уровней. |
| Static Surfaces Are Ground | Любая неподвижная (Static) поверхность тоже считается землёй. |
| Fall Y | Мышь, упавшая ниже −6 за край карты, побеждена. |
| Effect Material | Материал BPG/ComicFX для облачка пыли при исчезновении мыши. |

Спрайт мыши временный: `Assets/Sprites/Mouse/Mouse.png` (пиксель-арт 24×16, Pixels Per Unit = 10). Чтобы поставить свою текстуру, откройте `Mouse.prefab`, замените Sprite у SpriteRenderer и подгоните Size / Offset у CapsuleCollider2D под тело мыши (зелёная капсула в окне Scene). Изменения сразу применятся ко всем мышам на всех уровнях.

**Блоки** — `Assets/Prefabs/Blocks/WoodBlock.prefab` (дерево: одно попадание, плотность 0,25) и `StoneBlock.prefab` (камень: 3 попадания, сопротивление сдвигу 0,6, трение 1,8, плотность 0,6). Масса считается автоматически по площади (Rigidbody2D → Use Auto Mass). Текстуры `Assets/Sprites/Blocks/Wood.png` и `Stone.png` нарисованы в режиме Tiled с рамкой 9-slice, поэтому блок любого размера выглядит аккуратно: размер меняется полем SpriteRenderer → Size, и такой же Size нужно поставить у BoxCollider2D. Auto Tiling у коллайдера блока выключен: с ним Unity сама пересчитывала коллайдер, и блоки проваливались сквозь землю. Для надёжности `LevelTarget` при запуске уровня всё равно выставляет коллайдер плиточного блока (Draw Mode: Tiled или Sliced) ровно по Size спрайта, а **BPG → Проверить интерфейс всех сцен** и `apply_layouts.py --check` сообщают о расхождении. Вертикальные стойки — это доски, повёрнутые на 90°. Размеры кратны 0,1 (один пиксель текстуры).

Счёт попытки: 1000 за сбитый блок, 5000 за побеждённую мышь, плюс разлёт блоков и бонус за экономию выстрелов. Поражение наступает, когда снаряды кончились, а снаряды, блоки и падающие мыши остановились.

Раскладки всех пяти построек описаны в `Tools/level_tools/level_layouts.py`; `apply_layouts.py` записывает их в сцены (заменяет только содержимое TargetArea и каменные площадки), а `gen_previews.py` рисует по ним превью карточек. Подробности — в `Tools/level_tools/README.md`.

Звёзды на карточках и в окне победы (`Assets/UI/Generated/StarOn.png`, `StarOff.png`) раньше были перевёрнуты лучом вниз; теперь они смотрят вверх. Их можно перерисовать скриптом `Tools/art_tools/gen_sprites.py`.
