# Пиксельный интерфейс и анимации ожидания

## Готовое оформление

Стиль: простые кремовые, лиловые и графитово-фиолетовые плашки с пиксельными краями. Дерево, доски и древесные текстуры в новых UI-ассетах не используются. При наведении и клавиатурном фокусе появляется только рыжая рамка; цвет самой кнопки сохраняется. Сжатие на 2%, возврат за 0,1 секунды и спокойное покачивание сохранены.

Настоящие рендеры Unity: `Design/PixelTheme/pixel-font-comparison.png`, `pixel-main.png`, `pixel-settings.png`, `pixel-tutorial.png`, `card-focus.png`, `button-focus.png`.

| Ассет | Для чего |
|---|---|
| `Assets/UI/PixelTheme/Sprites/ButtonPrimary.png` | Основное действие: играть, продолжить, начать |
| `ButtonSecondary.png` | Назад, настройки, повторить и другие действия |
| `ButtonLight.png` | Светлая дополнительная кнопка |
| `ButtonIcon.png` | Кнопка с отдельной иконкой поверх |
| `PanelDark.png` | Меню, результаты, пауза, счёт, карточки |
| `PanelLight.png` | Плашка с текстом или изображением |

Все шесть спрайтов импортированы как `Sprite / Single`, `Filter Mode: Point`, без сжатия и mipmaps. Указаны границы для 9-slice. На `Image` используйте `Type: Sliced`, чтобы менять размер, сохраняя края.

Готовые заготовки находятся в **`Assets/Prefabs/UI/PixelTheme`**: четыре кнопки и две панели. У новой кнопки назначьте собственный `Button → On Click`; у квадратной кнопки добавьте дочернюю `Image` с иконкой и отключённым `Raycast Target`.

Общий стиль — **`Assets/Resources/MenuButtonStyle.asset`**. `Highlighted Color` управляет цветом рамки, `Focus Frame Width` — её толщиной. `MenuControlFeedback → Shared Focus Color` включает рамку для конкретного контрола; его поля нажатия и покачивания работают как раньше. У карточки есть свой `Shared Focus Color` и `Hover Frame Width`.

## Шрифты и переключение

Основной шрифт — **Tiny5**. Он близок к пиксельным персонажам и подходит для основного интерфейса. **Press Start 2P** — более широкий аркадный вариант; хорош для заголовков и коротких кнопок. **Handjet** — узкий вариант для компактных подписей. Все три проверены по полному русскому алфавиту, включая Ё/ё; добавлены статические TTF и готовые TMP Bitmap-ассеты с Point-фильтрацией атласа.

Источники: [Tiny5](https://github.com/google/fonts/tree/main/ofl/tiny5), [Press Start 2P](https://github.com/google/fonts/tree/main/ofl/pressstart2p), [Handjet](https://github.com/google/fonts/tree/main/ofl/handjet). Исходные файлы и OFL находятся в `Assets/UI/PixelTheme/Fonts/Sources`. При распространении проекта сохраняйте лицензии. Pixelify Sans исключён: в проверенном файле из Google Fonts отсутствуют О и П; его исходник оставлен в `Design/PixelTheme/RejectedFonts` для воспроизводимости проверки.

Чтобы сменить шрифт во всей игре:

1. Выберите `Assets/Resources/MenuButtonStyle.asset`.
2. В поле **Font** назначьте `Tiny5-Pixel`, `PressStart2P-Pixel` или `Handjet-Pixel` из `Assets/UI/PixelTheme/Fonts`.
3. В меню Unity выберите **BPG → Оформление → Обновить шрифт из MenuButtonStyle**. Команда сохранит шрифт во всех сценах и UI-префабах; при необходимости подстройте размер длинных надписей.

`Style-Tiny5.asset`, `Style-PressStart2P.asset` и `Style-Handjet.asset` — готовые варианты для сравнения. Команда **BPG → Оформление → Применить пиксельный стиль ко всем интерфейсам** повторно применяет основной стиль Tiny5; она не удаляет назначенные кадры анимации и не меняет On Click.

## Куда вставлять кадры анимации

На всех пяти префабах котов в **`Assets/Prefabs/Cats/Cat1…Cat5.prefab`** и всех пяти префабах мышей в **`Assets/Prefabs/Mouses`** уже установлен компонент **Idle Sprite Animation**. Отдельные Animator Controller и Animation Clip создавать не требуется.

1. Импортируйте свои кадры в `Assets` — например, в `Assets/Art/IdleFrames/Cats/Cat1` или `Assets/Art/IdleFrames/Mice/EasyEnemy`. При отдельных PNG установите `Texture Type: Sprite (2D and UI)`, `Sprite Mode: Single`. Для общего листа — `Sprite Mode: Multiple`, затем `Sprite Editor → Slice → Apply`.
2. Выставьте `Filter Mode: Point`, отключите сжатие и mipmaps. У кадров должны совпадать **Pixels Per Unit**, размер холста и **Pivot** с обычным спрайтом персонажа. Тогда персонаж не будет прыгать или менять размер при смене кадра. Коллайдеры остаются прежними.
3. Откройте нужный **префаб**, а не отдельный экземпляр в сцене. В **Idle Sprite Animation → Frames** задайте размер массива и перетащите спрайты по порядку. Для листа кадров перетащите текстуру в **Лист кадров** и нажмите **Заполнить кадрами из листа**. Кадры сортируются по имени с учётом номера: `idle_1`, `idle_2`, …, `idle_10`. В листе должны находиться кадры только одной нужной анимации.
4. Настройте **Frames Per Second** — по умолчанию 6. **Ping Pong** проигрывает кадры туда и обратно. **Varied Start** даёт экземплярам разную начальную фазу. **Предпросмотр без запуска игры** показывает кадры в редакторе; остановка и закрытие инспектора восстанавливают исходный спрайт. Используется штатный Unity Animation Mode.
5. Сохраните префаб. Все использующие его сцены и коты, создаваемые катапультой, получат эти кадры автоматически.

Коты проигрывают кадры **только в очереди**. При загрузке в катапульту и выстреле используется `CatProjectile → Launch Sprite`, как раньше. Мыши проигрывают кадры, пока живы и стоят: `Only When Still`, `Still Speed` и `Still Angular Speed` задают пороги остановки. На паузе кадры замерзают. Анимация смерти мыши сохраняется. Пустой массив `Frames` оставляет прежний вид; ваши кадры пока не назначены, поскольку они не были приложены к этому запросу.

Отключить анимацию можно галочкой компонента **Idle Sprite Animation** либо очисткой массива `Frames`.

## Проверка

Игровые скрипты и редакторские инструменты скомпилированы. В отдельном проекте Unity выполнены статические рендеры; проверены исходные обработчики и доступность кнопок, подключение компонентов на 10 префабах и полный русский алфавит. При переносе оформления сохранены исходные параметры физики, камеры, атмосферы, способностей и уровней. Play Mode и игровые проверки не запускались.
