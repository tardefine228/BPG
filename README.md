# BPG — «коты против мышей»

2D-аркада на Unity: рогатка-катапульта запускает котов по постройкам, чтобы
раздавить мышей и разобрать ящики. В полёте каждому коту доступна своя
способность, за уровень дают до трёх звёзд, за серию прохождений открываются
новые карты.

* Движок: **Unity 6000.6.5f1**, URP 2D, Input System, uGUI + TextMeshPro.
* Сцены: `Boot → MainMenu → Gameplay → Level2 → Level3 → Level4 → Level5`
  (см. `ProjectSettings/EditorBuildSettings.asset`).
* Игра запускается с `Assets/Scenes/Boot.unity` — там заставка и переход в меню.
* Целевая платформа проекта — десктоп (1920×1080), управление мышью и клавиатурой.

## Как запустить

1. Склонировать репозиторий с Git LFS (`git lfs install` до клонирования):
   часть ассетов (png, wav, mp3, ttf) хранится в LFS.
2. Открыть папку проекта в Unity Hub версии **6000.6.5f1** и дождаться импорта
   пакетов из `Packages/manifest.json`.
3. Открыть `Assets/Scenes/Boot.unity` и нажать **Play**. При запуске прямо из
   уровня или `MainMenu` заставка пропускается, остальное работает как обычно.
4. Номер уровня для отладки задаётся в `LevelSession → Forced Level Id` на
   объекте `GameManager` внутри сцены.

## Управление

| Действие | Клавиши |
| --- | --- |
| Натянуть катапульту | ЛКМ по коту / площадке |
| Выстрелить | отпустить ЛКМ |
| Отменить натяжение без расхода выстрела | ПКМ |
| Способность кота в полёте | ЛКМ или Пробел |
| Пауза / настройки | Escape |
| Навигация по меню | мышь, стрелки, влево/вправо для страниц уровней |

## Геймплей

* Пять котов-снарядов (`Assets/Prefabs/Cats/Cat1…Cat5`) с разными
  способностями: рывок, умножение, взрыв, увеличение массы, пикирование
  (`Assets/Scripts/Abilities`).
* Боезапас уровня — 2 / 3 / 4 / 5 / 5 котов; в катапульте сразу сидит один, за
  выстрелом следующий занимает его место.
* Победа — убиты все обязательные мыши; если коты кончились, подводится
  частичный итог. Звёзды: 3 за всех обязательных мышей, иначе
  `ROUND(убитые / всего × 3)`, но неполный результат даёт 1–2 звезды; без
  единого убийства — поражение.
* Уровни открываются по звёздам: 2-й — после прохождения 1-го, далее — за
  5, 8 и 12 собранных звёзд (`LevelProgress.Levels`).
* Мыши различаются запасом здоровья — от лёгких до танков и босса; обязательные
  для победы помечены `Counts For Victory`. Объекты уровней — ящики, планки,
  бронированные блоки с несколькими попаданиями, взрывные бочки, плиты.

## Структура проекта

| Путь | Что там |
| --- | --- |
| `Assets/Scripts` | игровой код: `Gun/SlingshotController`, `LevelScripts`, `Enemies/MouseEnemy`, `Abilities`, `Cameras`, `ProjectileS`, `MenusScripts`, `SceneTrans`, `AudioS` |
| `Assets/Scenes` | заставка, меню и пять уровней |

| `Assets/Editor` | проверка сцен (меню **BPG → Проверить интерфейс всех сцен**) и установка пиксельного стиля |
| `Tools` | вспомогательные скрипты на Python/PowerShell |
| `Design/PixelTheme` | рендеры и исходники пиксельного оформления |

## Инструменты

Внешних зависимостей почти нет — для большинства скриптов достаточно Python 3.

```bash
python3 Tools/level_tools/gen_levels.py     # сцены Level2..5 (сейчас защищён проверкой: UI живёт в сценах)
python3 Tools/level_tools/gen_previews.py   # превью-картинки карточек меню
python3 Tools/audio_tools/gen_sfx.py        # синтез звуков выстрела и побед
python3 Tools/audio_tools/import_meows.py   # мяуканье из реальной CC0-записи (numpy, soundfile)
```

`Tools/design` переносит пиксельное оформление на сцены и проверяет результат,
`Tools/particles_and_ammo/verify_compile.ps1` компилирует игровые скрипты, а
`Tools/validation/run_play_checks.ps1` прогоняет play-проверки в копии проекта
через отдельный Unity (`ValidationRunner.cs`, `VisualPreviewRunner.cs`).
