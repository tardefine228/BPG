# Оформление меню и отклик способностей

## Настройки в Inspector

В `MainMenu` выберите кнопку и откройте существующий `MenuControlFeedback`:

| Поле | Значение | Что меняет |
| --- | --- | --- |
| Idle Sway | включено | Покачивание этой кнопки |
| Sway Angle | 0,45° | Максимальный наклон |
| Sway Distance | 0,7 | Вертикальное смещение в единицах Canvas |
| Sway Frequency | 0,18 | Частота; один цикл примерно за 5,6 секунды |
| Press Compression / Press Amount | включено / 0,02 | Сжатие кнопки на 2% при нажатии |
| Press Return Duration | 0,1 секунды | Плавное возвращение после отпускания; работает в паузе |
| Shared Focus Color | включено | Общий тёплый цвет наведения и выбора с клавиатуры |

Движение идёт в реальном времени, имеет разные фазы и восстанавливает исходную позу при закрытии панели или отключении компонента. Оно включено у существующих кнопок MainMenu, включая настройки и выбор уровней. У Slider и Toggle компонент продолжает отвечать за прежние звуки, сами ползунки и переключатели не качаются. Кнопки игровых сцен не получают покачивание автоматически.

Сжатие также работает при подтверждении кнопки с клавиатуры; оно не усиливает покачивание. Общий цвет фокуса хранится в `Assets/Resources/MenuButtonStyle.asset → Highlighted Color`: тёплый кремово-золотистый `(255, 225, 176)`. Кнопки и ползунки используют его через `MenuControlFeedback`, карточки — через существующую рамку `LevelCardView`, включая выбор с клавиатуры. Изображение карточки не тонируется. `Shared Focus Color` можно отключить отдельно у контрола или карточки.

## Подсказки и сила натяжения

На катапульте в `SlingshotController` доступны следующие настройки:

| Поле | Назначение | По умолчанию |
| --- | --- | --- |
| Shot Hints | Значок способности, название и подсказки управления | включено |
| Ability Badge Offset / Cancel Hint Offset | Положение подсказок относительно заряженного кота, в единицах Canvas | (0; 78) / (-120; -52) |
| Weak Pull Dot Scale / Strong Pull Dot Scale | Размер точек при слабом / полном натяжении относительно Trajectory Dot Pixels | 0,65 / 1,25 |

Подсказка способности — одна компактная тёмная плашка с инструкцией **«ЛКМ / ПРОБЕЛ в полёте»**. Она показывается только в `Gameplay`, для первого кота с активной способностью, и больше не повторяется у других котов или на других уровнях. Флаг `BPG.Guide.AbilityUsed.v2` сохраняется при этом выстреле. Названия способностей и отдельные значки убраны.

После выстрела плашка следует за выпущенным котом и полностью исчезает при активации или потере возможности применить способность. При натяжении она скрывается, чтобы не закрывать первые точки траектории, и появляется короткая подсказка **«ПКМ — отменить»**. Правая кнопка мыши отменяет натяжение без расхода выстрела. В паузе, обучении, загрузке и на экране результата подсказки скрываются. Они не перехватывают клики.

Размер точек плавно растёт вместе с натяжением, дополняя прежний цвет. Расчёт полёта и положение точек сохранены. Подсказки созданы один раз и управляются существующим `SlingshotController`; новых игровых скриптов не добавлено.

Перед одноразовым обучением показывается `Assets/UI/Tutorial/IntroComic.png`, почти на весь экран, с сохранением пропорций. Нижняя встроенная подпись закрыта тёмной плашкой. Через две секунды реального времени появляется **«нажмите, чтобы продолжить»**. Любая свежая клавиша клавиатуры или кнопка мыши открывает две прежние иллюстрации «Натяни» / «и стреляй»; удержание до окончания задержки не пропускает комикс. Нажатие перехода не закрывает сразу и вторую страницу. Игровая пауза сохраняется до кнопки начала игры в обучении.

Параметры комикса находятся в `FirstLevelGuide`: `Comic Sprite`, `Comic Continue Delay` (2 секунды) и `Comic Footer Height` (0,09). Контекстное меню **«Сбросить показ обучения первого уровня»** сбрасывает комикс, обучение и одноразовую подсказку способности. Для локальной проверки из редактора можно также создать игнорируемый Git файл `Temp/BPG-reset-first-guide.once`: следующий запуск Gameplay сбросит только эти флаги и удалит маркер.

У `ProjectileComicEffects` на Cat2–Cat5 доступны `Ability Effects`, `Ability Effect Scale` и четыре цвета. Способности используют существующий `ComicEffectsPool`: каждый слот один раз подготавливает небольшой процедурный меш для вспышек и штрихов, затем переиспользует его.

| Параметр способности | Назначение |
| --- | --- |
| Ability Effect Scale | Общий размер относительно видимого радиуса персонажа; по умолчанию 1,45 |
| Ability Intensity | Интенсивность вспышек, колец и частиц; по умолчанию 1 |
| Ability Pulse Duration | Продолжительность импульса в игровых секундах; по умолчанию 0,72 |
| Ability Stroke Width | Толщина молний, колец и скоростных штрихов |
| Split / Speed / Blast / Inflate Effect Scale | Отдельный размер каждого вида эффекта |
| Ability Trail Duration / Width Multiplier | Продолжительность и ширина усиленного цветного следа |
| Speed Effect Scale | Размер компактного эффекта ускорения; 0,62 |
| Speed Pulse Duration | Длительность импульса ускорения; 0,32 секунды |
| Speed Trail Duration / Width Multiplier | Продолжительность и ширина следа ускорения; 0,45 секунды / 1,25 |
| Split Effect Scale / Split Pulse Duration | Размер и длительность вспышки разделения; 0,65 / 0,42 секунды |
| Split Trail Width Multiplier | Ширина более слабого голубого следа копий; 1,35 относительно обычного |

| Кот | Сохранённая способность | Визуальный отклик |
| --- | --- | --- |
| Cat1, обычный | Обычный выстрел | Прежний след |
| Cat2, жёлтый | `DiveCatAbility`: ускорение вниз | Небольшой тонкий золотой зигзаг, семь коротких штрихов и маленькие искры; без колец, звезды, большого ореола и дыма |
| Cat3, голубой | Три копии вместо оригинала | Одно небольшое полупрозрачное голубое кольцо, шесть коротких штрихов и 14 маленьких искр; без звёзд, ореола и дыма. Следы копий тоньше, короче и слабее, сохраняют голубой цвет до приземления |
| Cat4, серый | Взрыв | Две огненные волны, звёздная бело-жёлтая вспышка, искры и клубки дыма |
| Cat5, трёхцветный | Рост размера и массы | Пульсирующее двойное кольцо, расходящиеся лучи и пух |

`DashCatAbility`, если его назначить префабу, тоже получает золотой эффект. Сила, масса, урон, число копий, ввод и момент доступности способностей сохранены. Эффекты останавливаются на паузе и затухают; вспышка разделения живёт в пуле после удаления оригинала. Взрыв больше не создаёт Texture2D и Sprite при каждом срабатывании.

Перезарядка: в `SlingshotController → Spawn Delay` на катапульте задержка после завершения полёта уменьшена с 2,5 до 2 секунд. Значение сохранено во всех пяти игровых сценах и в настройках нового компонента. Ожидание окончания полёта и анимация посадки следующего кота работают по прежним правилам.

## Лесной туман и свет

В каждой игровой сцене (`Gameplay`, `Level2`–`Level5`) выберите **Main Camera → ForestAtmosphere**. Шейдер рисует светлую дымку преимущественно внизу кадра: сплошной слабый слой и широкие струи с плавными краями. Свет образуется из нерегулярных просветов в листве, широкого рассеянного свечения и медленно движущихся пятен. Размеры и промежутки просветов различаются; повторяющихся полос нет. Полосы интерфейса и кнопки остаются сверху; исходные цвета спрайтов не меняются. Это процедурный художественный слой для 2D-сцены, без объёмного расчёта теней.

| Поле в Inspector | Что регулирует | По умолчанию |
| --- | --- | --- |
| Fog Enabled / Fog Opacity | Включение и максимальную непрозрачность тумана | включён / 0,075 |
| Fog Color | Оттенок дымки | светлый молочно-зелёный |
| Fog Density / Fog World Scale | Плотность и размер струй | 0,72 / 30 |
| Fog Height | Высота середины плавного затухания от нижнего края кадра | 0,35 |
| Fog Height Falloff | Полуширина перехода к прозрачному небу | 0,30 |
| Fog Drift | Направление и скорость струй в единицах мира за секунду | (0,18; 0,008) |
| Light Enabled | Включение лучей и световых пятен | включён |
| Ray Intensity / Dapple Intensity | Яркость рассеянного света и лучей / пятен на объектах | 0,035 / 0,018 |
| Sunlight Color | Оттенок лесного света | бледный тёплый |
| Light World Scale | Размер рисунка света | 21 |
| Ray Angle / Ray Width | Наклон и мягкую ширину лучей | 24° / 0,72 |
| Light Animation Speed / Light Shimmer | Скорость и силу переливания | 0,24 / 0,22 |
| Animation Speed | Общий темп атмосферы; 0 останавливает рисунок | 1 |
| Seed | Другой рисунок света и дымки | различный на каждом уровне |
| Preview In Edit Mode / Animate In Edit Mode | Предпросмотр и его анимацию в редакторе | включён / выключена |

**Отключение:** снимите галочку у самого компонента **ForestAtmosphere** — исчезнет весь слой, и его материал и меш будут освобождены. Для раздельного отключения снимите **Fog Enabled** или **Light Enabled**. Чтобы ослабить слой, уменьшите **Fog Opacity**, **Ray Intensity** и **Dapple Intensity**. Чтобы туман занимал больше нижней части экрана, увеличьте **Fog Height**; для более плавного растворения увеличьте **Fog Height Falloff**. **Animation Speed = 0** останавливает движение, сохраняя видимый слой. Изменения на Main Camera относятся к выбранной сцене.

Материал `Assets/Materials/ForestAtmosphere.mat` явно назначен в сценах; шейдер `Assets/Resources/Shaders/ForestAtmosphere.shader` сохранится в сборке. Крупных текстур для атмосферы нет.

## Звуки

Во всех пяти сценах коробки и мыши используют общие скрипты и существующие клипы из `Assets/Resources/Audio`. У мыши писк теперь срабатывает также при гибели от пола и уроне способностью; смертельное попадание звучит один раз. У коробок урон способностью тоже включает звук. Коробки проигрывают его через AudioManager, с общим управлением громкостью и паузой, без временного AudioSource на каждый удар.

## Проверка

`Tools/particles_and_ammo/verify_compile.ps1` проверяет компиляцию игровых скриптов.

`Tools/validation/run_play_checks.ps1 -DesignOnly -MinimalEditor` запускает Unity в отдельной копии проекта с отдельными PlayerPrefs. Проверяет реальные клики по меню и настройкам, ползунки, листание карточек, обучение, четыре способности на каждом из пяти уровней, частицы на паузе и их очистку, звуки попаданий способностями и гибели от пола. Сохраняет кадры меню, карточек, обучения и способностей. Для проверки обычных выстрелов и очереди остаётся `-CatFlightOnly`.

Полный проход этой правки: `Tools/validation/run_play_checks.ps1 -DesignOnly -CatFlightOnly -MinimalEditor`. Проверка времени жизни после попадания учитывает значение Inspector в префабе, а не фиксированные 3 секунды из старого теста.

Проверка атмосферы сравнивает реальные рендеры с включённым и выключенным слоем: дымка должна быть видна и оставаться слабой, кнопка паузы — одинаковой. Дополнительно проверяются движение, остановка на паузе, формат 4:3 / 16:9, отключение и повторное включение без дублирования слоя.

Проверено 12.10.2026 в Unity 6000.6.5f1: компиляция — PASS; меню, настройки, обучение, 20 активаций способностей на пяти уровнях, остановка частиц на паузе и очистка, звуки мышей и коробок — PASS. Отдельная проверка обычных выстрелов, очереди, повторных столкновений, качения, паузы, ожидания последнего снаряда и рестарта Gameplay/Level2 — PASS; земля и очередь Level3–Level5 — PASS. Кадры обучения, карточек и эффектов просмотрены. Игровых ошибок в этих проверках нет.

После усиления VFX и добавления лесной атмосферы выполнен общий проход `-DesignOnly -CatFlightOnly`: **PASS**. На всех пяти уровнях проверены реальные рендеры тумана и света, неизменный HUD, пауза, форматы 4:3 / 16:9 и повторное включение без лишних объектов. Просмотрены кадры светлой и тёмной карт и каждой способности; дефолты атмосферы уменьшены после визуальной проверки тёмной карты.

После последующей переработки нижней дымки, нерегулярного света и компактной молнии проверены только компиляция и визуальные кадры, по просьбе пользователя. `Tools/validation/VisualPreviewRunner.cs` запускается исключительно в отдельной копии проекта с companyName `BPGChecks`, в редакторе, без Play Mode, ввода, симуляции физики или запуска способностей. Сохранены кадры всех пяти сцен с отключённой атмосферой и с временем шейдера 0 / 60 / 120 секунд, а также эффект ускорения крупным планом. Unity завершилась с кодом 0; сообщений компилятора шейдера нет. Игровое тестирование этой версии остаётся пользователю.

13.10.2026: для подсказок, размера точек и общего фокуса проверены компиляция и статичные кадры Unity через `VisualPreviewRunner.Run -bpgInteractionVisuals`. Просмотрены подсказки четырёх способностей, потускневший значок, слабое и сильное натяжение, компактная подсказка ПКМ, нажатая кнопка, рамка карточки и ползунок.
